Collection details

Grouped by the major product areas in your current app.

Rules-backed DB map
users

Identity, roles, suspension

Stores profile info, `is_admin`, `is_staff`, therapist flags, push token, blocked/suspended account state.

posts / comments / postVotes

Feed data

Posts, replies, vote records, toxicity flag fields, hidden/approved moderation states.

conversations / messages

DM system

Participant conversation docs plus message docs for anonymous DMs, therapist sharing, and shared posts.

reports / notifications

Moderation and alerts

User-created reports, admin resolution workflow, warning notifications, booking/game/moderation alerts.

groups / group_members

Groups and challenge membership

Challenge setup, creator/admin roles, auto-added members, member labels, proof and activity linkage.

group_invitations

Group invite flow

Tracks inviter, target user, group id, pending/accepted/declined state, and auto-join related logic.

therapist_onboarding_requests

Therapist verification

Uploaded document checklist, verification video, admin status, reviewed notes, completed therapist UID.

therapist_profiles / slots

Marketplace availability

Verified therapist profile data, public list view, appointment slots, booked slot counts and availability.

therapist_sessions / reviews

Session lifecycle

Confirmed sessions, session messages, crisis signal, private session review, aggregate therapist reviews.

therapist_resources

Learning resources

Admin/therapist-created videos, PDF books, and article resources with files stored in Cloud Storage.

live_podcast_rooms

Live podcast rooms

Room metadata, host UID, co-host IDs, approved speaker UIDs, replay flags, room lifecycle.

transcripts / speaker_requests

Live subtitles and access

Subcollection transcript segments plus speaker access request docs managed by host/function workflow.
